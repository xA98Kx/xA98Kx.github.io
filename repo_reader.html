repo_reader_

read code from any github repo on your phone. paste a link, pick a branch, pick a file, read.

built for phones

wrap or scroll

wrap long lines to fit your screen, or turn it off for line numbers and side scrolling.

your text size

tap Aa in any file to make the code bigger or smaller. it remembers your choice.

big tap targets

every row is at least 48px tall, and inputs never trigger zoom on iOS.

back just works

your phone's back gesture closes a file and returns you to the list.

find files fast

search every path in a branch, or tap through folders with breadcrumbs.

shareable links

the address updates as you browse, so you can bookmark or home-screen a file.

tip: on iPhone use Share → Add to Home Screen to open it like an app.

token (private repos or rate limits)

stored only in this browser. read-only contents access is enough.
